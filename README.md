# Movie Watch Website

A simple private video library for videos you own or are authorized to stream.

## Features
- Upload videos
- Video library with posters/titles
- Online HTML5 streaming
- Simple login/password gate
- Mobile-friendly UI

## Run
1. Install Node.js 18+.
2. Open a terminal in this folder.
3. Run:
   npm install
   npm start
4. Open http://localhost:3000

Default demo password: `friends123`

For real internet use, deploy the Node app on a server and put it behind HTTPS. Use cloud/object storage for large videos rather than relying on local disk.
